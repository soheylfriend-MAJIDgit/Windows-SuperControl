# Windows-SuperControl

دو تا کد پایتون خیلی ساده که با هم هماهنگ شدند:

| # | کجا | چی کار میکنه |
|---|-----|--------------|
| 1 | این ریپازتوری (`launcher.py` + `run.bat`) | یه فایل bat تعاملی + یه پنجره ساده با **یک دکمه**. با زدن دکمه، کد پایتون رو مستقیم از نت (همون پوشه گوگل درایو) میگیره و اجرا میکنه. |
| 2 | [پوشه گوگل درایو](https://drive.google.com/drive/folders/1PmMAu537pzN3mjKf_PYctUOlbOIQCUf1) | فایل `salam.py.txt` — محتواش پایتونه و پیام «سلام مجید جان…» رو با یه دکمه «بله» نشان میده. |

یک کپی دقیق از فایل درایو هم توی `payloads/salam.py` هست (برای وقتی که نت قطع باشه، و برای محاسبه هش).

---

## اجرا (ویندوز)

1. پایتون ۳ نصب باشه. موقع نصب حتماً تیک **Add Python to PATH** و **tcl/tk and IDLE** رو بزن (برای پنجرهها لازمه).
2. این ریپازتوری رو روی کامپیوترت داشته باش (همونجایی که الان تو گیتهاب هست).
3. روی `run.bat` دوبار کلیک کن. یه منوی ساده میاد، `1` رو بزن.
4. پنجره «Windows SuperControl» باز میشه. فقط یه دکمه داره: **دریافت و اجرا**. بزنش.

### میخوای از دسکتاپ بازش کنی؟

راست click روی `run.bat` ← **Send to** ← **Desktop (create shortcut)**. تموم.
(چون `run.bat` از `%~dp0` استفاده میکنه، از هر جایی که اجراش کنی، مسیر ریپازتوری رو پیدا میکنه.)

اگه خواستی با PowerShell بسازیش:

```powershell
$repo = "C:\path\to\Windows-SuperControl"
$s = (New-Object -ComObject WScript.Shell).CreateShortcut("$env:USERPROFILE\Desktop\Windows SuperControl.lnk")
$s.TargetPath = "$repo\run.bat"
$s.WorkingDirectory = $repo
$s.Save()
```

## جریان کار (هماهنگی دوتا کد)

```
run.bat  →  launcher.py  →  دریافت salam.py.txt از گوگل درایو
                          →  چک SHA-256
                          →  نشان دادن متن کد تو پنجره
                          →  تاییدیه «اجرا بشه؟»
                          →  اجرا تو پروسه جداگانه  →  پیام «سلام مجید جان… بله … همین.»
```

اگه درایو جواب نده، سراغ [`raw.githubusercontent.com`](https://github.com/soheylfriend-MAJIDgit/Windows-SuperControl) میره، و اگه اونم نبود، از `payloads/salam.py` (نسخه آفلاین) استفاده میکنه.

**چرا پسوند فایل درایو `.txt` شد؟**
چون گوگل درایو برای فایلهای `.py` صفحه «Virus scan warning» برمیگردونه و اجازه دانلود مستقیم نمیده. محتوا دقیقاً همون کد پایتونه، فقط اسمش `salam.py.txt` گذاشته شده تا دانلود مستقیم کار کنه. برناممون موقع اجرا اون رو به اسم `downloaded_code.py` ذخیره میکنه.

---

## اگه خواستی پیام توی درایو رو عوض کنی

1. فایل `salam.py.txt` رو توی درایو ویرایش کن (و بهتره `payloads/salam.py` رو هم همجوره کنی).
2. هش جدید رو بهدست بیار:

   ```bat
   python launcher.py --hash payloads\salam.py
   ```

   یا توی PowerShell: `Get-FileHash payloads\salam.py -Algorithm SHA256`
3. مقدار `EXPECTED_SHA256` توی `launcher.py` رو عوض کن.

تا وقتی هش عوض نشه، برنامه عمداً از اجرای فایل جدید جلوگیری میکنه (امنیت).

همه تنظیمات (آیدی فایل درایو، آدرسها، تایماؤت، تاییدیه) بالای `launcher.py` توی بخش «تنظیمات» هستن.

## نکتههای امنیتی (مهم)

- این برنامه **هر کدی رو که از اون پوشه بگیره اجرا میکنه**. پس پوشه درایو رو فقط خودت کنترل کن.
- دسترسی پوشه درایو قبلاً `هرکس با لینک = نویسنده (writer)` بود؛ من به `هرکس با لینک = فقط خواندن (reader)` تغییرش دادم تا غریبهها نتونن فایل رو عوض کنن. دانلود مستقیم همچنان کار میکنه. اگه خواستی برگردونیش، توی Drive روی پوشه راستکلیک → Share کنید.
- علاوه بر اون، هش SHA-256 فایل توی `launcher.py` پین شده؛ حتی اگه کسی فایل درایو رو عوض کنه، برنامه اجراش نمیکنه.
- هیچ اجرای خودکار، استارتآپ، سرویس یا مخفیکردن پنجرهای وجود نداره. هر بار فقط با کلیک خودت و یه تاییدیه اجرا میشه. متن کامل کد هم قبل از اجرا جلوی چشمت نمایش داده میشه.
- کد دانلودشده توی `%TEMP%\Windows-SuperControl\downloaded_code.py` ذخیره میشه و میتونی بعداً ببینیش.
