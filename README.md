# Windows-SuperControl

**همه کدها توی گوگل درایواند. گیت هاب فقط یه دکمه است.**

```
  run.bat  →  bootstrap.py  →  [ اینترنت ]  →  main.py.txt  (گوگل درایو)
                                                  ↓
                                        برنامه اصلی اجرا میشود
                                    (دو تب: دریافت و اجرا / ارسال نامه)
```

یعنی: روی `run.bat` دوبار کلیک میکنی → یه پنجره کوچک با **فقط یک دکمه** باز میشه →
«**شروع**» رو میزنی → برنامه اصلی مستقیم از گوگل درایو دانلود و اجرا میشه.
دکمه میشه «**توقف**»؛ بزنیش برنامه بسته میشه.

✅ **هر تغییری که توی فایلهای درایو بدیم، همون لحظه تو اجرای بعدی اعمال میشه.**
دیگه لازم نیست گیت هاب آپدیت بشه، چیزی دانلود کنی یا فایلی رو کپی کنی.

> ### 🔴 فقط یک کار لازم داری (یک بار، ۱۰ ثانیه)
> فایل **`config.txt` توی پوشه درایو** رو باز کن و آدرس وب اپ Apps Scriptـت رو
> جلوی `WEBAPP_URL=` بچسبون. این آدرس پیش من نیست، برای همین توی فایل خالی گذاشتم.
> بدون اون، تب «ارسال نامه» فقط بهصورت محلی کار میکنه و نمیتونه توی درایو بنویسه.
> (همون URLـی که قبلاً توی فایل قدیمی `launcher.py` پر کرده بودی. پیداش نکردی؟
> `script.google.com` → پروژهت → Deploy → Manage deployments → Web app URL.)
>
> بقیه چیزها — از جمله `main.py.txt` — آمادهست و من مستقیم توی درایو ادیتشون میکنم.

## کجا چی هست؟

### توی گیت هاب (فقط ۲ فایل واقعی)

| فایل | کارش |
|---|---|
| `run.bat` | دوبار کلیک → پنجره کنترل باز میشه |
| `bootstrap.py` | پنجره تکهدکمه «شروع / توقف» + دانلود و اجرای برنامه از درایو |
| `README.md` | همین متن |

### توی [پوشه گوگل درایو](https://drive.google.com/drive/folders/1PmMAu537pzN3mjKf_PYctUOlbOIQCUf1) (منبع اصلی)

| فایل | کارش |
|---|---|
| **`main.py.txt`** ⭐ | **برنامه اصلی** — تمام امکانات (دو تب، ارسال نامه، استعلام، گزارش زمانی). هر ادیتی اینجا زده بشه مستقیم اعمال میشه. |
| **`config.txt`** ⚙️ | تنظیمات قابل ویرایش: `WEBAPP_URL` و `WEBAPP_SECRET` |
| `salam.py.txt` | کد پیام «سلام مجید جان… بله… همین» که تب ۱ اجراش میکنه |
| `name.txt` | فایل زنده نامهها |
| `Code.gs.txt` | کد وب اپ Apps Script (واسه نوشتن نامه توی درایو) |

> پسوند `.txt` گرفتن چون گوگل درایو اجازه دانلود مستقیم فایل `.py` نمیده و یه صفحه
> «Virus scan warning» برمیگردونه. محتوا پایتونه؛ bootstrap موقع اجرا ذخیرهاش میکنه
> به اسم `main.py`.

## راهاندازی (فقط یک بار)

1. **پایتون ۳** نصب باشه. موقع نصب تیک **Add Python to PATH** و **tcl/tk and IDLE** رو بزن.
2. **`config.txt` توی درایو** رو باز کن و آدرس وب اپ Apps Scriptـت رو جلوی `WEBAPP_URL=` بچسبون:
   ```
   WEBAPP_URL=https://script.google.com/macros/s/AKfycb......../exec
   ```
   (همون URLـی که قبلاً توی `launcher.py` پر کرده بودی. اگه یادت نیست: برو
   `script.google.com` → پروژهت → **Deploy → Manage deployments** → کپی «Web app URL».)
   
   جایگزین: یه فایل `config.txt` کنار `bootstrap.py` بساز؛ اون اولویت داره و توی گیت نمیره.
3. اگه وب اپ رو با نسخه قبلی `Code.gs` دیپلوی کردی، یه بار **Deploy → Manage deployments →
   New version → Deploy** بزن (قابلیت استعلام رو اضافه کرده). URL عوض نمیشه.
4. روی `run.bat` دوبار کلیک کن و «شروع» رو بزن. تمام.

واسه دسکتاپ: راستکلیک روی `run.bat` ← **Send to** ← **Desktop (create shortcut)**.

## نحوه کار دکمه

**شروع:**
1. `main.py.txt` و `config.txt` رو مستقیم از گوگل درایو دانلود میکنه.
2. چک میکنه محتوا واقعاً کد باشه (نشانگر `WSC-MAIN-PROGRAM`، UTF-8، نه صفحه HTML).
3. هش SHA-256 ش رو با دفعه قبل مقایسه میکنه. اگه عوض شده باشه (یعنی کد آپدیت شده)
   یه پیام تایید با چند خط اول کد نشون میده — یه بار «بله» بزن. اگه نخواستی،
   توی `config.txt` بذار `AUTO_TRUST=yes` تا دیگه نپرسه.
4. کد رو توی کش محلی مینویسه (`%APPDATA%\WindowsSuperControl\main.py`) و اجراش میکنه.
5. **خروجی و خطاهای برنامه اصلی توی همین پنجره نشون داده میشه** — پس اگه چیزی کار نکرد،
   دقیقاً میبینی چرا.

**توقف:** برنامه اصلی رو همراه تمام زیردستهایش میبنده (`taskkill /T /F` تو ویندوز).
بستن پنجره کنترل هم همین کارو میکنه.

**آفلاین:** اگه درایو در دسترس نبود، از آخرین نسخه کششده استفاده میکنه و توی لاگ هشدار میده.

## عیبیابی (واسه وقتی «کار نکرد»)

- لاگ توی پنجره کنترل مرحلهبهمرحله نشون میده کجا گیر کرده (دریافت، هش، اجرا، خطای پایتون).
- خط فرمان:
  ```bat
  run.bat diagnose
  ```
  یا `python bootstrap.py --diagnose` — بدون پنجره، وضعیت درایو، هش، کانفیگ و کش رو چاپ میکنه.
- محل فایلها:
  ```
  %APPDATA%\WindowsSuperControl\
      main.py          آخرین نسخه اجراشده
      config.txt       کپی کانفیگ درایو
      trusted.json     هش نسخه تاییدشده
      cache\salam.py   کش کد پیام
      letters\         نامهها + report.csv
  ```

## امنیت

- ⚠️ **دسترسی پوشه درایو رو از `هرکس با لینک = نویسنده` برگردوندم به `فقط خواندن`.**
  دلیل: الان کد اجرایی از این پوشه دانلود و روی کامپیوترت اجرا میشه. اگه پوشه
  «رایت آزاد برای همه» بمونه، هرکس لینک رو داشته باشه میتونه `main.py.txt` رو عوض کنه
  و کد خودشو اجرا کنه. **نامهها همچنان کار میکنن**، چون وب اپ با حساب **خودت** مینویسه
  (نیازی به دسترسی نوشتن عمومی نداره).
  اگه حتماً خواستی برگردونیش: توی Drive روی پوشه راستکلیک → Share → «Editor».
- حتی با این حال، bootstrap هش برنامه رو نگه میداره و هر بار که عوض بشه بهت خبر میده
  (مگه اینکه `AUTO_TRUST=yes` بذاری). پس یه فایل دستکاریشده بیتوجه اجرا نمیشه.
- `salam.py.txt` هم داخل برنامه اصلی **هش پینشده** داره؛ کسی نمیتونه جاش یه کد دیگه بذاره.
- آدرس وب اپ و رمزت توی `config.txt` درایوه (که حالا فقط خودت میتونی ویرایشش کنی).
  اگه ترجیح میدی لوکال بمونه، یه `config.txt` کنار `bootstrap.py` بساز — توی `.gitignore` هست.
- هیچ اجرای خودکار، استارتآپ، سرویس یا مخفیکاریای وجود نداره. فقط با زدن «شروع» اتفاقی میافته.

## امکاناتی که سر جاشونه

برنامه اصلی همون قبلیه، فقط خونهاش عوض شده:

- **تب ۱ «دریافت و اجرا»** — کد رو از `salam.py.txt` میگیره، هش چک میکنه، نشونت میده،
  تایید میگیره، اجرا میکنه.
- **تب ۲ «ارسال نامه»** — ذخیره آنی (۰.۸ ثانیه بعد از تایپ)، استعلام بعد از ذخیره،
  و گزارش زمانی `نوشتن / استعلام / کل / تفاوت` توی `letters/report.csv`.
- گزینههای خط فرمان برنامه اصلی: `--hash`، `--send "متن"`، `--check`.

برای ویرایش هرکدوم، مستقیم برو توی `main.py.txt` توی درایو. دفعه بعد که «شروع» رو بزنی،
نسخه جدید اجرا میشه.
